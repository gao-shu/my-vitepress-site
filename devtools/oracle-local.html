本地 Oracle 安装配置（Windows） ​

下载说明 ​

⚠️ 重要提示：Oracle Database 是商业数据库，需要注册 Oracle 账号才能下载。

  • 官方下载地址：https://www.oracle.com/database/technologies/oracle-database-software-downloads.html
  • 推荐版本：Oracle Database 21c Express Edition (XE) - 免费版本，适合学习和开发
  • XE 版本限制：
    • 最大数据量：12 GB
    • 最大内存使用：2 GB RAM
    • 最大 CPU 使用：2 个线程

安装步骤 ​

1. 下载安装包 ​

  1. 访问 Oracle 官网下载页面
  2. 选择 Oracle Database 21c Express Edition for Windows x64
  3. 接受许可协议
  4. 登录 Oracle 账号（没有则注册）
  5. 下载文件：WINDOWS.X64_213000_db_home.zip（约 2.5 GB）

2. 解压安装包 ​

bash
# 创建安装目录
mkdir C:\oracle

# 将下载的 zip 文件解压到该目录
# 注意：必须直接解压到 oracle 目录，不要有多层嵌套

3. 运行安装程序 ​

  1. 以管理员身份打开命令提示符（CMD）或 PowerShell
  2. 进入解压目录：
    bash
    cd C:\oracle
    1
  3. 运行安装命令：
    bash
    setup.exe
    1

4. 安装向导配置 ​

  1. 配置选项：

    • 选择"创建和配置数据库"
    • 系统类：选择"桌面类"（Desktop Class）

  2. 典型安装配置：

    • Oracle 基目录：C:\oracle
    • 软件位置：C:\oracle\product\21c\dbhomeXE
    • 数据库文件位置：C:\oracle\oradata
    • 数据库版本：企业版
    • 全局数据库名：XE
    • 管理口令：设置 SYS 和 SYSTEM 用户密码（记住此密码！）

  3. 先决条件检查：

    • 确保有足够的磁盘空间（至少 10 GB）
    • 确保有足够的内存（至少 2 GB）
    • 关闭所有占用端口的应用程序

  4. 开始安装：

    • 点击"安装"按钮
    • 等待安装完成（通常需要 20-40 分钟）
    • 记录安装日志中的信息

  5. 完成安装：

    • 安装完成后会显示 Database Control URL
    • 通常是：https://localhost:5500/em
    • 点击"关闭"完成安装

监听器配置 ​

配置文件位置：C:\oracle\product\21c\dbhomeXE\network\admin\listener.ora

ini
# listener.ora Network Configuration File

SID_LIST_LISTENER =
  (SID_LIST =
    (SID_DESC =
      (SID_NAME = CLRExtProc)
      (ORACLE_HOME = C:\oracle\product\21c\dbhomeXE)
      (PROGRAM = extproc)
      (ENVS = "EXTPROC_DLLS=ONLY:C:\oracle\product\21c\dbhomeXE\bin\oraclr21.dll")
    )
    (SID_DESC =
      (SID_NAME = XE)
      (ORACLE_HOME = C:\oracle\product\21c\dbhomeXE)
    )
  )

LISTENER =
  (DESCRIPTION_LIST =
    (DESCRIPTION =
      (ADDRESS = (PROTOCOL = TCP)(HOST = localhost)(PORT = 1521))
      (ADDRESS = (PROTOCOL = IPC)(KEY = EXTPROC1521))
    )
  )

SQL*Plus 常用命令 ​

sql
-- 连接到数据库
CONNECT username/password@XE

-- 查看当前会话信息
SELECT sid, serial#, username, status FROM v$session WHERE username IS NOT NULL;

-- 查看表空间使用情况
SELECT tablespace_name, 
       ROUND(SUM(bytes) / 1024 / 1024, 2) AS used_mb
FROM dba_segments 
GROUP BY tablespace_name;

-- 查看用户列表
SELECT username, created, account_status FROM dba_users ORDER BY created DESC;

-- 解锁用户
ALTER USER hr ACCOUNT UNLOCK;
ALTER USER hr IDENTIFIED BY hr_password;

-- 查看正在执行的 SQL
SELECT sql_id, sql_text, elapsed_time 
FROM v$sql 
ORDER BY elapsed_time DESC 
FETCH FIRST 10 ROWS ONLY;

-- 查看锁信息
SELECT l.session_id, o.object_name, l.locked_mode
FROM v$locked_object l
JOIN dba_objects o ON l.object_id = o.object_id;

-- 杀死会话
ALTER SYSTEM KILL SESSION 'sid,serial#';

-- 导出数据库（使用 Data Pump）
-- 在命令行执行：
-- expdp system/password@XE DIRECTORY=data_pump_dir DUMPFILE=backup.dmp FULL=Y

-- 导入数据库

Oracle SQL Developer（图形化工具） ​

下载安装 ​

  • 下载地址：https://www.oracle.com/tools/downloads/sqldev-downloads.html
  • 推荐下载：SQL Developer 21.4 或更高版本
  • 无需安装，解压即可使用（需要 JDK 11 或更高版本）

配置连接 ​

  1. 打开 SQL Developer
  2. 点击"新建连接"（绿色 + 号）
  3. 填写连接信息：
    • 连接名称：XE_Local
    • 用户名：system 或 sys
    • 口令：安装时设置的密码
    • 主机名：localhost
    • 端口：1521
    • SID：XE
  4. 点击"测试"验证连接
  5. 点击"连接"

常用功能 ​

  • 📝 编写和执行 SQL 脚本
  • 📊 可视化查看表结构和数据
  • 🔍 执行计划和性能分析
  • 📦 数据库对象管理（表、视图、存储过程等）
  • 📤 数据导入/导出
  • 🔄 数据库迁移工具

5. 内存占用过高 ​

Oracle XE 默认使用较多内存，可以调整：

sql
-- 连接到数据库
sqlplus / as sysdba

-- 查看当前内存使用
SHOW PARAMETER memory_target;
SHOW PARAMETER sga_target;
SHOW PARAMETER pga_aggregate_target;

-- 调整内存参数（需要重启数据库）
ALTER SYSTEM SET memory_target=1G SCOPE=SPFILE;
ALTER SYSTEM SET sga_target=700M SCOPE=SPFILE;
ALTER SYSTEM SET pga_aggregate_target=300M SCOPE=SPFILE;

-- 重启数据库
SHUTDOWN IMMEDIATE;
STARTUP;

6. 表空间不足 ​

-- 查看表空间使用情况
SELECT tablespace_name, 
       ROUND(used_space * 8192 / 1024 / 1024, 2) AS used_mb,
       ROUND(tablespace_size * 8192 / 1024 / 1024, 2) AS total_mb,
       ROUND(used_percent, 2) AS used_percent
FROM dba_tablespace_usage_metrics;

-- 扩展表空间
ALTER DATABASE DATAFILE 'C:\ORACLE\ORADATA\XE\SYSTEM01.DBF' 
RESIZE 2G;

-- 或添加新的数据文件
ALTER TABLESPACE USERS 
ADD DATAFILE 'C:\ORACLE\ORADATA\XE\USERS02.DBF'
