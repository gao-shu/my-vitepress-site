# 关于我

## 我为什么做这个网站？

**最核心的目标：通过输出倒逼输入，把学习变成可复用的长期资产。**

这个网站是我的 **Second Brain（第二大脑）**。不限于开发，后续会把各个方面的学习总结都汇总到这里，例如：

- 💻 **开发与技术**：Java、数据库、框架、工业数字化等
- 📝 **求职笔记**：面向求职的系统整理
- 🤖 **AI**：大模型、Agent、工具链与项目实践
- 🌱 **运动健身**：睡眠、训练计划、久坐与肩颈等
- 💰 **财务**：记账、应急金、理财认知等
- 🗣️ **语言与表达**：英语口语等

通过系统整理和输出，我希望自己能够：

- 📝 **加深理解**：写出来，才算真正学进去
- 🎯 **建立体系**：把零散知识点串成完整框架
- 🔄 **持续迭代**：随着学习深入不断更新，留下成长轨迹
- 💡 **发现盲区**：整理时暴露不会的地方，明确下一步方向

## 次要目标：知识分享

在自我学习的同时，我也希望这些内容能够：

- 🌱 帮到同样在学习的人
- 📚 提供一条可参考的学习路径
- 🤝 方便交流，互相纠错与补充

## 我的学习方式

- **系统化学习**：按模块整理，构建完整知识体系
- **实战驱动**：结合项目与生活实践，学以致用
- **输出倒逼输入**：通过写作加深理解，发现盲区
- **持续更新**：内容会长期迭代，不追求一次写完

---

> 💭 **我的理念**：最好的学习方式之一，就是尝试把事情讲清楚。Second Brain 是学习路上的见证，也是持续进步的动力。

感谢你的访问。如果内容对你有帮助，我会很开心；如果发现错误或不足，也欢迎指正——那同样是我的学习机会。
