# 英文技术面试

这不是英语学习栏目，也不是语法 / 单词 / 雅思教程。

定位只有一句话：

> **把已经掌握的技术能力，用简单、稳定、清楚的英语表达出来，以便参加英文技术面试。**

我的问题不是不懂 Java，而是：面试官用英语问我时，能不能快速、简单地讲清楚。

---

## 为什么做这个专题

目标链路：

```text
技术能力
  ↓
英文表达
  ↓
英文技术面试
  ↓
英文远程岗位
```

我有 10+ 年 Java / 全栈经验，做过企业业务系统和 MES / 工业数字化，正在往 AI 应用 / Agent 方向转，也在找远程开发岗位。

不需要从零学英语。需要的是：**把已有技术能力，转成能开口的面试表达。**

---

## 90 天目标

### 能说清楚自己

- 30 秒自我介绍
- 60 秒自我介绍
- 90 秒自我介绍

### 能讲清楚项目

至少 3 个：

1. MES / 工业数字化
2. 企业级 Java / 全栈
3. AI 应用 / Agent / AI 漫剧平台

每个项目按同一骨架讲：

```text
Background → Responsibility → Tech Stack → Architecture
→ Challenge → Solution → Result
```

没有真实数据就不虚构；正在做的写成 design / prototype / current development。

### 能回答技术问题

Java、JVM、并发、MySQL、Redis、MQ、Spring、微服务、分布式、AI、Agent——用英语解释，不重新学一遍技术。

### 能处理真实面试交流

这些不是「英语技巧」，是英文技术面试的生存能力：

| 情况 | 可以说 |
| ---- | ---- |
| 没听懂 | Sorry, could you repeat the question? |
| 需要确认 | Do you mean the database consistency issue? |
| 需要思考 | Let me think about that for a moment. |
| 不会 | I haven't worked with it directly, but I've worked with similar technologies. |
| 举例 | Let me explain it with an example. |
| 换说法 | Let me rephrase that. |
| 纠正自己 | Let me correct that. / Let me rephrase that. |

英文面试不是演讲，是技术沟通。听不懂、不确定、需要举例，都是正常沟通动作。
