# DevOps（面试 + 实战）

就业侧只关心一件事：**你能不能把代码稳定送到环境里，出问题能不能快速定位。**  
不背工具百科，按「面试怎么问 → 你怎么答 → 你怎么做」准备。

## 建议阅读顺序

1. [Docker 实战与面试](./docker-interview) — 容器、镜像、常见命令、上线相关问题  
2. [CI/CD 实战与面试](./cicd-interview) — 流水线怎么讲、最小可落地配置  
3. [监控排查实战与面试](./monitoring-interview) — 指标/日志/告警，线上怎么查  

## 面试官通常想听什么

- 你是否亲手搭过或改过流水线 / 容器部署  
- 出故障时你的排查顺序（先看什么、再看什么）  
- 能不能说清一次真实经历：构建失败、发布回滚、内存打满等
