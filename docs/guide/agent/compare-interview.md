## 口述参考

### IDE 结对 vs 终端 Agent vs 云端委托

| 形态 | 代表 | 适合 | 面试怎么说 |
|------|------|------|------------|
| AI IDE | Cursor、Copilot | 日常改代码、可控 | 人在环，节奏快 |
| 终端 Agent | Claude Code、Codex CLI | 多文件、长任务 | 权限与 diff 要审 |
| 云端委托 | Devin、部分 Cloud Agent | 异步出 PR | 范围要写清，适合明确票 |

金句：**日常提效用 IDE；深改用终端；异步票才考虑强委托。**

### 自研 vs 产品

- 业务要接内部 OA/ERP、强权限审计 → 自研编排 + 官方模型 API 更常见。  
- 纯研发提效 → 直接产品（Cursor 等），别重复造 IDE。  
- 自研价值在：**工具契约、状态机、与领域系统集成**，不在再做一个聊天窗。

### 为何不一步「全自动」

- 范围不清时全自动 = 大规模误改。  
- 先人审 diff / 先确认表单，再扩大自主。  
- 体现你有工程判断，不是追概念。

### 国内产品

- 数据合规、内网、腾讯/阿里云生态 → 国内助手有场景。  
- 能力与生态仍快速变化；选型讲 **场景与约束**，不讲粉圈。
