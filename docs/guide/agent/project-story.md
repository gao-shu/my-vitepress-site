## 按你简历可挂的钩子

### AI 漫剧内容生产

- 钩子：多模型 API、异步任务、状态回写、失败重试  
- Agent 表述：偏 **编排 + 工具化调用**；若某步有模型选工具，再提 Tool Calling  
- 别只说「用了 AI」，说「任务怎么不丢、怎么重试、怎么验收」

### 钢瓶轻量 MES / 工业

- 钩子：多端、采集、现场联调  
- Agent 表述：现场更适合 **RAG 问答 + 严格禁止自动控设备**；未来助手也是「建议」不是「直写 PLC」  
- 体现判断力：工业场景的边界意识

### AI Coding 提效

- 钩子：Cursor 工作流、Code Review、小 Bug 闭环  
- 表述：人定范围与验收，Agent 加速编辑；合入前有测试/人审

## 常见追问速答

- 「和 ChatGPT 网页差在哪？」→ 我们有状态、权限、业务 API，可审计。  
- 「效果怎么量化？」→ 成功率、重试次数、人工介入率、费用（有数说数）。  
- 「最大踩坑？」→ 准备 1 个真实坑：超时未重试 / 状态不一致 / 提示词无版本…  
- 「可靠性一开始怎么设计的？」→ 背四件套：超时、重试（读写分开）、幂等 key、审计字段；多 Agent 再说总超时 vs 单步 timeout。
