## 怎么用

| 顺序 | 页 | 目的 |
|------|-----|------|
| 0 | [高频快答](./quick-qa) | 一面 30～60 秒速过 + 追问链 |
| 1 | [概念与边界](./concepts-interview) | 分清 Chat / Agent / RAG / 微调 |

---

## 30 秒自我定位（可背）

> 我理解的 Agent 不是更会聊天，而是 **目标 + 工具 + 循环**：模型决策，业务系统执行，有步数上限、权限和可观测。多数业务先 Prompt / 结构化输出，知识问题用 RAG，真要多步办事再上 Agent。
