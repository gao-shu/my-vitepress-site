## 常见追问

- 「内存泄漏？」→ 监听未移除、定时器未清、全局缓存；开发时用 Performance 看。  
- 「如何热更新配置？」→ 点表热加载要谨慎，写操作中更新要有版本号。  
- 「和纯 Vue Web 区别？」→ 本地能力与设备；部署是安装包不是只刷新 CDN。
