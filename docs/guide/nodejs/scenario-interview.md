# Node.js / TS 面试 · 实战场景题

---

## 答题骨架

1. 进程职责怎么分  
2. 异步与超时  
3. 失败可见、可重试  
4. 安全边界  
5. 和 Java 后端如何协作  

---

## 题 A：本地 BFF 聚合三个 HTTP 接口

**要点：** 并行 `Promise.allSettled`；部分失败仍返回；统一超时；缓存可选项；密钥不进前端。

---

## 题 B：Electron 页面要点表「写寄存器」

**要点：** UI 只发 IPC；主进程校验地址范围与权限；二次确认；操作审计日志；失败回滚提示。

---

## 题 C：设备断线重连

**要点：** 状态机（连接中/已连接/重连中）；退避间隔；UI 显示最后错误时间；恢复后补读关键点。

---

## 题 D：导出上万行 CSV 不卡死

**要点：** Stream 边查边写；或主进程导出；别一次拼巨大字符串；进度条用 IPC 推送。

---

## 题 E：Node 脚本 vs Java 服务怎么选

**要点：** 临时工具 Node/Python；长期权限、事务、集群 Java。体现选型。

---

## 收尾

> 「桌面端先保证主进程不堵、设备操作可审计；再谈漂亮 UI。」
