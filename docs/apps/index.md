# 应用开发

从业务需求出发，利用软件、AI 与自动化技术，构建解决实际问题的应用。

这里展示的是**能做什么** —— 按应用场景分类的项目、解决方案与实践案例。每个案例展示问题、实现方案、效果截图、源码或演示入口。

## 分类

| 分类 | 内容 | 说明 |
|------|------|------|
| [AI 应用](/apps/ai/) | 智能体、知识库、工作流 | 用大模型与 Agent 做出来的应用 |
| [办公自动化](/apps/office/) | 飞书、企微、钉钉 | 围绕办公 IM 的机器人与流程自动化 |
| [业务应用](/apps/business/) | Web、SaaS、小程序、公众号 | 面向业务的管理系统与 C 端应用 |
| [终端应用](/apps/terminal/) | 移动端、PDA、桌面端、上位机 | 多端交付与硬件交互类应用 |
| [系统集成](/apps/integration/) | API、Webhook、数据同步 | 系统之间打通与数据流转 |
| [工业与物联网](/apps/industrial/) | MES、PLC、设备监控 | 现场采集与生产管理类应用 |
| [部署与运维](/apps/ops/) | Docker、NAS、自托管 | 让应用跑起来并稳定运行 |

## 定位说明

- **应用开发** 与 [AI 赋能](/ai/) 有交集，但定位不同：这里以**应用和项目成果**为主，AI 赋能以 **AI 实践过程与成长**为主。
- 不为填满分类刻意开发项目。先把已有的真实项目和工作经验整理出来，再逐步增加 AI 应用、自动化等新案例。
- 以后无论做微信小程序、飞书机器人、AI Agent，还是 C# 上位机，都有地方放，网站整体不会因新技术出现而频繁改版。
