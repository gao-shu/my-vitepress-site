# 效率与自动化工具

> 提升效率、减少重复劳动 —— 把搬运、提醒、汇总、定时这些动作交给机器。

本页是 04 类的**分类总览**，覆盖四个子域。当前内容以办公协同自动化为多，其余子域逐步补充。

| 子域 | 做什么 | 入口 |
|---|---|---|
| 办公协同自动化 | 飞书/企微/钉钉机器人、消息推送、日报周报、日程会议 | 见下表 |
| 流程与待办 | 审批触发通知、待办聚合、超时催办、状态回写 | [审批与待办自动化](/apps/office/approval-automation) |
| 个人效率 | 任务时间管理、个人知识库、开发者工具箱 | [个人效率实例](/instances/tools/) |

> PDA、桌面端、上位机等端上交付内容已独立为 [05 多端应用与现场交付](/apps/terminal/)。

**项目状态图例**：✅ 已验证（有运行/测试证据） · 🔧 验证中/在建（代码存在，证据整理中） · 📋 规划中（尚未开始）

## 📋 办公协同自动化

| 文章 | 解决的问题 |
|------|-----------|
| [飞书机器人开发实践](/apps/office/feishu-bot) | 自建应用与机器人、事件订阅（消息/审批）、卡片交互与权限鉴权，以及常见踩坑 |
| [企微/钉钉消息推送与 Webhook](/apps/office/im-webhook) | 群机器人 Webhook 与应用消息选型、签名校验、限流重发与统一模板消息设计 |
| [日报周报自动生成](/apps/office/report-auto-generation) | 数据源接入与指标口径统一、模板渲染、AI 摘要、定时生成推送与人工确认环节 |
| [日程与会议自动化](/apps/office/schedule-sync) | 多端日历同步、会议预约与分级提醒、纪要分发归档、与任务系统联动闭环 |
