# 库位分配与上架策略

> 收货后货物放哪个库位、如何避免乱放与爆仓。关联实例：[WMS 仓储管理](/instances/industrial/wms)。

## 问题

- 收货后凭经验放货，库位混乱、拣货找不到。
- 库位容量无约束，容易爆仓 / 混放。

## 方案

- **三级库位**：仓库 → 库区 → 库位；库位承载**容量与状态**（空闲 / 占用 / 满 / 锁定）。
- **上架策略**（可配置）：
  - **就近**：同库区 / 同品类就近空位
  - **固定**：SKU 绑定固定库位
  - **随机**：就近有空位即放（提高空间利用率）
  - **ABC 分类**：高频品放近端
- **容量约束**：库位剩余容量 ≥ 入库量才可分配。

## 落地要点

```text
推荐接口：输入 (sku, 数量) → 返回候选库位列表（按策略排序，过滤容量不足 / 锁定）
分配成功后：写库位占用 + 库存与库位关系
```

## 取舍

- 策略越智能，实现越重；中小仓先用「就近 + 容量约束」即可，后续再加 ABC / 波次。
