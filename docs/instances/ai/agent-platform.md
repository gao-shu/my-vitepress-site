# AI 工作流与智能体平台

> 状态：📋 规划中（尚未开始实现） · 所属模块：[03 AI 应用](/instances/ai/) · 模块内优先级：第 3 位

## 核心功能

| 功能 | 规划说明 |
|---|---|
| 工作流编排 | 可视化流程设计、节点编排、条件分支与循环 |
| 智能体配置 | 角色设定、提示词模板、模型选择、记忆配置 |
| 工具调用 | 工具注册中心、参数 schema、执行结果回传 |
| 任务自动化 | 定时/事件触发、批量执行、执行日志与回溯 |

## 规划要点

- 技术路线：Spring Boot + LangChain4j + MCP + Vue 3 流程设计器；编排 + 配置化是三者中最大的工程
- 建议前两个项目（AI 知识库、AI 智能助手）闭环后再启动，复用其网关、工具调用与检索能力
- 展示价值：智能体工作流平台是 AI 应用方向的集大成者，技术展示度最高
