# AI 智能助手

> 状态：📋 规划中（尚未开始实现） · 所属模块：[03 AI 应用](/instances/ai/) · 模块内优先级：第 2 位

## 核心功能

| 功能 | 规划说明 |
|---|---|
| 多模型接入 | OpenAI 兼容网关、多供应商密钥管理、模型路由与降级 |
| 智能对话 | 多轮会话、上下文管理、流式输出、会话历史 |
| 文件分析 | 文档解析、内容摘要、关键信息抽取 |
| 工具调用 | Function Calling / MCP 工具注册与执行 |

## 规划要点

- 技术路线：以已验证的 [ModelDesk](/apps/ai/modeldesk) 为基座（多模型接入 + OpenAI 兼容网关 + 模型对比已 ✅ 验证），向「助手产品化」方向补对话管理与文件分析，或合并 Java Agent 示例的 Tool Calling / MCP 能力
- 与 ModelDesk 的分工：ModelDesk 是配测台（面向开发者），本助手是应用（面向终端用户），两者共享网关层
- 展示价值：求职目标「AI 应用方向」最直接的产品化载体

## 与现有资产的关系

- 基座：[ModelDesk](/apps/ai/modeldesk)（✅ 已验证：619 个包、93 项单测、v0.2.1 已发布）
- 能力补充：Java Agent 示例（🔧 验证中：Tool Calling / MCP / Multi-Agent）
