## 核心功能

| 功能 | 规划说明 |
|---|---|
| 文档管理 | 文档上传、解析、分块、版本管理 |
| 知识检索 | 向量检索 + 关键词混合检索、相似度排序 |
| 智能问答 | RAG 问答、多轮追问、引用定位 |
| 来源引用 | 答案溯源到原文片段、文档与页码定位 |

## 规划要点

- 技术路线：Spring Boot + LangChain4j + pgvector/向量数据库 + Vue 3，直接复用 java-langchain4j-lab 已有代码补齐闭环
- 数据模型：文档 / 分块 / 向量索引 / 问答会话，重点是检索质量评估（命中率 + 引用准确率）
- 展示价值：RAG 全链路（解析-索引-检索-生成-引用），AI 应用方向最具代表性的工程闭环
