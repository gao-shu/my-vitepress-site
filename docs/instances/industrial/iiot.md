# 工业物联网监控系统

> 状态：📋 规划中（尚未开始实现） · 所属模块：[02 工业数字化应用](/instances/industrial/) · 模块内优先级：第 2 位

## 核心功能

| 功能 | 规划说明 |
|---|---|
| 设备数据采集 | MQTT/Modbus 协议接入、边缘网关数据上报、点位配置 |
| 运行监控 | 实时看板、设备状态、工艺参数可视化 |
| 异常告警 | 阈值规则、告警触发、通知渠道与告警升级 |
| 趋势分析 | 历史曲线、同比环比、设备综合效率 OEE 统计 |

## 规划要点

- 技术路线：Spring Boot + MQTT Broker + 时序数据库（TDengine/InfluxDB 二选一）+ Vue 3 看板；采集 + 告警链路独立，可与 MES 并行验证
- 数据模型：设备点位 / 实时数据 / 告警规则 / 告警记录，重点是高频写入下的存储与查询性能
- 展示价值：物联网采集到监控告警的完整链路，技术栈差异化明显

## 与现有资产的关系

- 与 MES 共享设备台账模型，可在 EAM/MES 之后作为数据消费方接入
- PLC 采集、协议对接、设备监控的实践经验已沉淀在[功能开发 › 工业数字化应用](/apps/industrial/)
