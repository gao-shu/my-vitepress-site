# 02 工业数字化应用

> EAM、MES、工业物联网 —— 现场采集与生产管理类系统。

**项目状态图例**：✅ 已验证 · 🔧 验证中/在建 · 📋 规划中（尚未开始实现）

## 项目规划

| 序号 | 软件项目 | 核心功能 | 状态 |
|---|---|---|---|
| 1 | [设备资产管理系统 EAM](/instances/industrial/eam) | 设备台账、维修保养、资产生命周期管理 | 📋 规划中 |
| 2 | [生产执行管理系统 MES](/instances/industrial/mes) | 生产工单、工序管理、生产报工、质量追溯 | 📋 规划中 |
| 3 | [工业物联网监控系统](/instances/industrial/iiot) | 设备数据采集、运行监控、异常告警、趋势分析 | 📋 规划中 |

## 与现有内容的关系

- **MES 优先走扩展路线**：在建工单系统的工单-工序-状态机模型与 MES 的生产工单、工序管理天然同构，计划以其为基础扩展工序流转、报工与质检，而不是另起炉灶，见[功能开发 › 工业数字化应用](/apps/industrial/)
- 轻量 MES 落地、PLC 采集、协议对接、设备监控的实践经验已沉淀在[功能开发](/apps/industrial/)的技术实践页

## 优先级建议

1. **生产执行管理系统 MES**（复用工单系统底座，投入产出比最高）
2. **工业物联网监控系统**（采集 + 告警链路独立，可与 MES 并行验证）
3. **设备资产管理系统 EAM**（台账-保养周期模型清晰，适合作为第三个闭环）
