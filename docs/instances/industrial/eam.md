# 设备资产管理系统 EAM

> 状态：✅ 已试水验证（基于 OpenBiz 最小闭环跑通） · 所属模块：[02 工业数字化应用](/instances/industrial/) · 模块内优先级：第 3 位 · [查看实证](/apps/openbiz/eam)

## 核心功能

| 功能 | 规划说明 |
|---|---|
| 设备台账 | 设备档案、分类编码、技术参数、位置与归属管理 |
| 维修保养 | 保养计划、维修工单、备件领用、维修记录归档 |
| 资产生命周期 | 采购入库、启用、调拨、封存、报废全流程跟踪 |

## 规划要点

- 技术路线：Java 21 + Spring Boot 3 + Vue 3 + TypeScript + MySQL；台账-保养周期模型清晰，适合作为第三个闭环
- 数据模型：设备主数据 / 保养计划 / 维修工单 / 备件库存，维修工单可复用工单系统状态机
- 展示价值：设备全生命周期管理，贴合制造业信息化场景

## 与现有资产的关系

- 维修工单部分可复用在建 [OpenBiz 工单系统](/apps/business/)（🔧 验证中/在建）的工单模型
- 轻量 MES 落地、PLC 采集、设备监控的实践经验已沉淀在[功能开发 › 工业数字化应用](/apps/industrial/)

## 建设状态

已通过 OpenBiz 试水应用验证（资产 + 维修单双状态机 + 跨实体联动），实证见 [OpenBiz 实战 › EAM](/apps/openbiz/eam)。
