# BPM 业务流程管理系统

> 状态：✅ 已试水验证（基于 OpenBiz 最小闭环跑通） · 所属模块：[04 办公自动化](/instances/office/) · 模块内优先级：第 2 位 · [查看实证](/apps/openbiz/bpm)

## 核心功能

| 功能 | 规划说明 |
|---|---|
| 流程设计 | 可视化流程设计器、节点类型、表单绑定 |
| 审批规则 | 审批人策略（角色/上级/自由）、会签或签 |
| 条件分支 | 网关条件、分支规则、超时与自动提醒 |
| 流程执行 | 流程实例流转、任务处理、执行轨迹回溯 |

## 规划要点

- 技术路线：Java 21 + Spring Boot 3 + Vue 3 + TypeScript + MySQL；流程设计器 + 规则引擎，技术展示度最高
- 数据模型：流程定义 / 节点 / 连线 / 流程实例 / 任务实例，核心是实例状态机与并发任务处理
- 本模块定位：BPM 是办公自动化三项目的核心底座，OA 的审批中心与表单系统的数据入口都可复用它

## 与现有资产的关系

- 实践经验来自[功能开发 › 办公自动化](/apps/office/)的审批待办自动化与消息 Webhook 沉淀
- 与工单系统的状态机设计同构，可参考其节点流转模型
