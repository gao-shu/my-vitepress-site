# HRM 人力资源管理系统

> 📋 规划中（功能设计已覆盖约 60%） · 所属模块：[04 办公自动化](/instances/office/) · 模块优先级：第 1 位
> 替换说明：本页取代原「在线表单与数据收集系统」——表单是能力不是系统，已并入 [BPM](/instances/office/bpm) 作为内置表单引擎。

## 📌 项目简介

HRM（Human Resource Management）覆盖员工**「入转调离 + 考勤 + 薪酬 + 招聘 + 绩效」**的全生命周期，是企业里**全员高频**的独立系统。它不重复造流程与表单，而是复用 [BPM](/instances/office/bpm) 的审批引擎与内置表单能力，把人事事务沉淀为结构化数据。

- **面向用户**：HR（人事专员 / 主管）、员工（考勤 / 请假 / 工资条）、管理者（绩效 / 编制 / 人力成本）
- **核心价值**：把散落在 Excel、纸质单、群聊里的人事事务，变成可查询、可审批、可统计的结构化数据
- **为什么替换「在线表单」**：表单只是 BPM 的输入组件，而 HRM 是真正的独立系统且全员使用 —— 用它补齐办公模块的完整度更有价值

## 🗺️ 功能规划（覆盖约 60%）

> 按标准 HRM 约 10 个模块估算，本期覆盖 **6 个核心模块 ≈ 60%**；剩余约 40% 列入后续扩展。

### 🧩 本期核心（6 个模块，约 60%）

| 模块 | 关键能力 |
|---|---|
| 组织架构 | 部门树、岗位、编制、汇报关系 |
| 员工档案 | 入职 / 转正 / 调岗 / 离职、劳动合同、证照 |
| 考勤管理 | 打卡、排班、请假、加班、出差 |
| 薪酬管理 | 工资核算、社保公积金、个税、工资条 |
| 招聘管理 | 职位发布、简历库、面试安排、Offer |
| 绩效管理 | 目标设定、考核评分、结果分布 |

### 📋 后续扩展（剩余约 40%）

- [ ] 培训管理（课程 / 报名 / 学时）
- [ ] 员工自助（自助查询 / 申请 / 证明开具）
- [ ] 报表分析（人力成本、流动率、编制使用率）

## 🏗️ 技术架构

```
┌──────────────────────────────────────────────────────┐
│   表现层：Vue 3 + TypeScript（HR 工作台 / 员工自助）      │
├──────────────────────────────────────────────────────┤
│   HRM 应用层                                            │
│   组织架构 · 员工档案 · 考勤 · 薪酬 · 招聘 · 绩效          │
├───────────────────┬──────────────────────────────────┤
│   审批 / 流程       │   表单引擎（复用 BPM 内置）          │
│   （BPM 流程引擎）   │   JSON Schema 动态渲染 / 校验       │
├───────────────────┴──────────────────────────────────┤
│   OpenBiz 底座：多租户 / 权限 / 状态机 / 消息通知         │
├──────────────────────────────────────────────────────┤
│   数据层：MySQL 8（组织 / 员工 / 考勤 / 薪酬 / 招聘 / 绩效）│
└──────────────────────────────────────────────────────┘
```

- **HRM 是「业务组装层」**：组织、档案、考勤、薪酬是 HRM 自有领域；请假、加班、调岗、Offer 审批委托给 BPM。
- 所有能力跑在 OpenBiz 底座上，天然具备多租户、权限与状态机。

## 🧰 技术栈 / 开发语言

| 分层 | 技术 |
|---|---|
| 前端 | Vue 3 + TypeScript + Vite |
| 后端 | Java 21 + Spring Boot 3 |
| 数据库 | MySQL 8 |
| 底座 | OpenBiz（多租户 / 权限 / 状态机 / 动态表单） |
| 复用 | BPM 流程引擎（审批）、内置表单引擎 |
| 集成 | REST API + Webhook 消息通知 |
