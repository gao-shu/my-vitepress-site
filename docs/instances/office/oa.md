# OA 办公自动化系统

> ✅ 已验证（OpenBiz 最小闭环跑通） · 所属模块：[04 办公自动化](/instances/office/) · 模块优先级：第 3 位 · [查看实证 ↗](/apps/openbiz/oa)

## 📌 项目简介

OA（Office Automation）面向企业日常办公协同场景，把**待办、公告、申请、审批**等高频事务统一收口到一个系统里。它不重新发明流程引擎，而是在 [BPM](/instances/office/bpm) 的流程能力之上做「面向办公场景的应用组装」，目标是让「提申请 → 审批 → 归档」形成可追踪的闭环。

- **面向用户**：企业员工（提申请 / 看公告 / 处理待办）、审批人（处理审批流）、管理员（配置公告与申请模板）
- **核心价值**：把分散在群聊 / 邮件 / 纸质单里的办公事务，沉淀为可查询、可流转、可统计的结构化数据

## 🗺️ 功能规划

### ✅ 已实现（基于 OpenBiz 试水实证）

| 功能 | 说明 |
|---|---|
| 请假申请单 | 标准化申请单 + 状态机（草稿 → 审批中 → 通过 / 驳回） |
| 通知公告 | 公告发布、置顶、阅读回执 |
| 审批中心 | 审批流处理、审批记录查询 |
| 个人待办聚合 | 待办 / 已办查询 |

## 🏗️ 技术架构

### 平台 + 垂直定位

```
┌ 垂直应用层（薄：领域模型 + 表单/流程配置）
│   CRM · ERP · PMS · OA · BPM · HRM         ◀ 本页：OA
├ 平台内核 · OpenBiz（一次建深，覆盖通用能力约 80%）
│   多租户/数据隔离 · RBAC/行级权限 · 工作流引擎 · 动态表单引擎
│   审计日志 · 消息通知中心 · 导入导出/报表 · 开放 API/SSO
└ 数据层 · MySQL 8 · Redis · 对象存储 · 消息队列
```

OA 是**薄垂直层**：只做待办 / 公告 / 申请单与审批组装，流程、表单、权限、消息复用平台内核。

### 本模块内部结构

```
┌──────────────────────────────────────────────┐
│              表现层  (Vue 3 + TypeScript)       │
├──────────────────────────────────────────────┤
│   OA 应用层                                     │
│   ├─ 待办聚合        ├─ 通知公告                 │
│   └─ 申请单服务  ──► 审批中心                    │
│                        │                        │
│                        ▼                        │
│              BPM 流程引擎（流程 / 任务）          │
├──────────────────────────────────────────────┤
│   OpenBiz 底座：多租户 / 权限 / 状态机 /           │
│               动态表单 / 消息通知                  │
├──────────────────────────────────────────────┤
│              数据层  (MySQL 8)                   │
└──────────────────────────────────────────────┘
```

- **OA 是「应用组装层」**：公告、待办聚合是 OA 自有能力；审批流则委托给 BPM，避免重复造流程引擎。
- 所有能力跑在 OpenBiz 底座上，天然具备多租户、权限与状态机。
