# OA 办公自动化系统

> 状态：📋 规划中（尚未开始实现） · 所属模块：[04 办公自动化](/instances/office/) · 模块内优先级：第 3 位

## 核心功能

| 功能 | 规划说明 |
|---|---|
| 待办事项 | 个人待办汇总、已办查询、委托代理 |
| 通知公告 | 公告发布、置顶、阅读回执、分组推送 |
| 办公申请 | 请假、报销、用品申领等标准化申请单 |
| 审批中心 | 审批流处理、加签转办、审批记录查询 |

## 规划要点

- 技术路线：Java 21 + Spring Boot 3 + Vue 3 + TypeScript + MySQL；在 BPM 之上组装待办、公告与申请，最后做集成
- 与 BPM 的分工：BPM 提供流程引擎能力，OA 是面向办公场景的应用组装（待办聚合、公告、申请单模板）
- 展示价值：企业办公系统的完整功能面，适合展示业务集成能力

## 与现有资产的关系

- 底座依赖同模块的 BPM 流程能力，建议在 BPM 之后启动
- 飞书机器人、审批待办自动化、消息 Webhook 的实践经验已沉淀在[功能开发 › 办公自动化](/apps/office/)
