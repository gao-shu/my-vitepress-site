# 04 办公自动化

> 企业办公协同类系统：人事 / 审批 / 公告 / 流程。与「企业业务应用」按场景分工——本模块聚焦**办公协同**，企业业务应用聚焦**经营业务数据**；二者共用 OpenBiz 底座（多租户 / 权限 / 状态机 / 动态表单），技术实践页会有交叉引用。

**项目状态图例**：✅ 已验证 · 🔧 验证中 / 在建 · 📋 规划中（尚未开始实现）

## 📌 模块简介

本模块把企业里最高频的办公事务——**管人事、走审批、发公告、填表单、看数据**——用三个相互复用的系统收口：

- **HRM**：人力资源，覆盖员工入转调离、考勤、薪酬、招聘、绩效 —— **全员高频的独立系统**
- **BPM**：流程引擎，是审批流与状态机的统一底座，并内置表单引擎
- **OA**：在 BPM + 表单之上组装出的办公协同应用（待办 / 公告 / 申请 / 审批）

三者共享同一底座能力（审批流、消息通知、权限），建议作为一个**组合**规划，避免三个独立空壳。其中 **BPM 是核心底座**，OA 的审批中心与 HRM 的请假 / 调岗 / Offer 审批都可复用它。

> **关于「在线表单」**：表单是**能力**而非独立系统，已并入 BPM 作为内置表单引擎，不再单列为项目。

## 🧰 技术栈 / 开发语言

| 分层 | 技术 |
|---|---|
| 前端 | Vue 3 + TypeScript + Vite |
| 后端 | Java 21 + Spring Boot 3 |
| 数据库 | MySQL 8 |
| 底座 | OpenBiz（多租户 / 权限 / 状态机 / 动态表单） |
| 集成 | REST API + Webhook 消息通知 |

## 🚀 建设优先级与路线

1. **HRM 人力资源管理系统**（全员高频、补齐办公核心缺口，覆盖 6 大模块约 60%）
2. **BPM 业务流程管理系统**（流程设计器 + 规则引擎，技术展示度最高，且是其他系统底座）
3. **OA 办公自动化系统**（在 BPM 之上组装待办、公告与申请，已闭环）

> 当前 BPM 与 OA 已通过 OpenBiz 试水验证（最小闭环），HRM 处于功能设计完成、待实现阶段。
