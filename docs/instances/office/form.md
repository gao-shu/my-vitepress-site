# 在线表单与数据收集系统

> 状态：📋 规划中（尚未开始实现） · 所属模块：[04 办公自动化](/instances/office/) · 模块内优先级：第 1 位

## 核心功能

| 功能 | 规划说明 |
|---|---|
| 表单设计 | 拖拽式表单设计、布局配置、预览与发布 |
| 字段配置 | 字段类型、校验规则、必填与默认值 |
| 数据提交 | 匿名/实名提交、防重复、提交进度暂存 |
| 数据统计 | 数据列表、筛选导出、图表统计与报表 |

## 规划要点

- 技术路线：Java 21 + Spring Boot 3 + Vue 3 + TypeScript + MySQL + JSON Schema 动态表单渲染；字段配置 + 数据统计链路最短，适合快速闭环
- 数据模型：表单定义（JSON Schema）/ 字段 / 提交数据（EAV 或 JSON 列存储），核心是动态渲染与数据校验
- 展示价值：动态表单引擎 + 数据收集分析，独立成站也可作为其他系统的数据入口

## 与现有资产的关系

- 字段配置 + 数据提交完成后，可作为 OA 办公申请与 BPM 流程表单的底层能力复用
- 实践经验沉淀在[功能开发 › 办公自动化](/apps/office/)
