# 内置表单能力（BPM 组件）

> 🔧 已并入 [BPM 业务流程管理系统](/instances/office/bpm) 作为内置表单引擎，不再作为独立项目
> 所属模块：[04 办公自动化](/instances/office/)

## 📌 说明

「在线表单 / 数据收集」本质是**能力**而非独立系统：企业很少单独采购一套表单系统，表单通常是 **BPM / OA / 低代码平台的内置组件**。因此本页不再作为独立项目，而是作为 BPM 的内置表单引擎说明。

- **定位**：所有结构化数据的入口 —— 审批单、报销单、请假单、登记表，本质都是「表单 + 流程」
- **归属**：BPM 内置表单引擎
- **复用方**：OA 办公申请单、HRM 请假 / 调岗 / Offer 审批

## 🧩 能力清单

| 能力 | 说明 |
|---|---|
| 定义解析 | 表单用 JSON Schema 描述，前后端共享同一份定义 |
| 动态渲染 | 前端按 Schema 渲染，无需为每种表单写页面 |
| 字段与校验 | 字段类型、必填、默认值、校验规则 |
| 提交与防重 | 提交、暂存、防重复提交 |
| 数据沉淀 | 提交数据统一存储，供统计与导出 |

## 🏗️ 在模块中的位置

```
HRM / OA 应用层（申请单、审批单）
        │ 复用
        ▼
BPM 流程引擎
  ├─ 流程：定义 / 实例 / 规则 / 分支
  └─ 表单引擎：JSON Schema 动态渲染 / 校验 / 提交
        │
        ▼
OpenBiz 底座：多租户 / 权限 / 动态表单
```
