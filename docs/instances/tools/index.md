# 05 个人工具

> 任务时间管理、知识笔记、开发者工具箱 —— 自用优先的小工具。

**项目状态图例**：✅ 已验证 · 🔧 验证中/在建 · 📋 规划中（尚未开始实现）

## 项目规划

| 序号 | 软件项目 | 核心功能 | 状态 |
|---|---|---|---|
| 1 | [个人任务与时间管理系统](/instances/tools/task-time) | 待办清单、日程安排、优先级、时间统计 | 📋 规划中 |
| 2 | [个人知识库与笔记系统](/instances/tools/notes) | 笔记编辑、标签分类、全文搜索、知识整理 | 📋 规划中 |
| 3 | [开发者工具箱](/instances/tools/devtools) | JSON 格式化、文本比较、编码转换、正则测试 | 📋 规划中 |

## 与现有内容的关系

- **个人知识库与笔记系统** ← 在建的 java-langchain4j-lab（🔧 验证中）与其定位高度重合，优先把它做完而不是新开项目，见[功能开发 › AI 应用](/apps/ai/)
- **开发者工具箱** ← text-manager（📋 待验证整理，TypeScript + Tauri，代码已在 GitHub 公开）可作为起点扩展
- PDA、Electron、上位机、离线优先的多端实践经验已沉淀在[功能开发 › 个人工具](/apps/terminal/)

## 优先级建议

1. **个人知识库与笔记系统**（java-langchain4j-lab 直接复用，成本最低）
2. **个人任务与时间管理系统**（自用驱动，模型简单，适合验证「小闭环」方法论）
3. **开发者工具箱**（纯前端工具集，适合作为闲暇增量，不占用主线时间）
