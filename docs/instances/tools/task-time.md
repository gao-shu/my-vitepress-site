# 个人任务与时间管理系统

> 状态：📋 规划中（尚未开始实现） · 所属模块：[05 个人工具](/instances/tools/) · 模块内优先级：第 2 位

## 核心功能

| 功能 | 规划说明 |
|---|---|
| 待办清单 | 任务创建、清单分组、完成打卡 |
| 日程安排 | 日历视图、时间段安排、提醒设置 |
| 优先级 | 四象限优先级、截止时间、延期提醒 |
| 时间统计 | 耗时记录、分类统计、效率报表 |

## 规划要点

- 技术路线：Spring Boot + Vue 3 + TypeScript + SQLite/MySQL，自用驱动；模型简单，适合验证「小闭环」方法论
- 数据模型：任务 / 清单 / 日程 / 时间记录，轻量但完整的 CRUD + 统计聚合
- 展示价值：完整的产品设计 + 全栈实现 + 自用真实场景，体现「给自己造工具」的工程习惯
