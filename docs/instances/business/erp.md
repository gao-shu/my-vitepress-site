# ERP 企业资源管理系统

> 状态：📋 规划中（尚未开始实现） · 所属模块：[01 企业业务应用](/instances/business/) · 模块内优先级：第 3 位

## 核心功能

| 功能 | 规划说明 |
|---|---|
| 采购管理 | 采购申请、采购订单、到货入库、供应商对账 |
| 销售管理 | 销售订单、出库发货、应收账款、销售报表 |
| 库存管理 | 多仓库存、出入库单据、库存盘点、库存预警 |
| 供应商管理 | 供应商档案、评级、供货周期与价格管理 |

## 规划要点

- 技术路线：Java 21 + Spring Boot 3 + Vue 3 + TypeScript + MySQL；进销存单据流转是用例最完整的部分，建议按「采购-销售-库存」单链先行
- 数据模型：物料主数据 / 供应商 / 采购订单 / 销售订单 / 库存单据，关键在单据状态机与库存流水
- 展示价值：企业资源管理的完整单据链路，适合展示复杂业务建模能力

## 与现有资产的关系

- 模块多、边界大，建议在工单系统与项目管理系统验证后启动，复用其权限、多租户与单据状态机实践
- ERP 单据、多租户 SaaS 的实践经验已沉淀在[功能开发 › 企业业务应用](/apps/business/)
