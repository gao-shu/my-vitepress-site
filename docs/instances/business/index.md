# 03 企业业务应用

> CRM、ERP、项目管理 —— 企业经营管理类系统（客户 / 订单 / 项目等经营业务数据）。与「办公自动化」按场景分工：本模块聚焦经营业务，办公自动化聚焦协同审批；二者共用 OpenBiz 底座（多租户 / 权限 / 状态机），技术实践页会有交叉引用。

**项目状态图例**：✅ 已验证 · 🔧 验证中/在建 · 📋 规划中（尚未开始实现）

## 项目规划

| 序号 | 软件项目 | 核心功能 | 状态 |
|---|---|---|---|
| 1 | [CRM 客户关系管理系统](/instances/business/crm) | 客户档案、销售线索、商机管理、客户跟进 | 📋 规划中 |
| 2 | [ERP 企业资源管理系统](/instances/business/erp) | 采购、销售、库存、供应商及企业资源管理 | 📋 规划中 |
| 3 | [项目管理系统](/instances/business/pms) | 项目计划、任务分配、进度跟踪、团队协作 | 📋 规划中 |

## 与现有内容的关系

- 共享底座 **OpenBiz**（Java 21 / Spring Boot / MySQL，工单全生命周期 API：多租户 + 权限 + 状态机）是本项目矩阵的第一个落地工程，其底座能力被「企业业务应用」与「办公自动化」两模块共同复用（BPM 审批、动态表单等同构），见[功能开发 › 企业业务应用](/apps/business/)
- 管理后台、CRM 定制、ERP 单据、多租户 SaaS 的实践经验已沉淀在[功能开发](/apps/business/)的技术实践页

## 优先级建议

1. **项目管理系统**（与工单系统任务模型最接近，复用度最高）
2. **CRM 客户关系管理系统**（线索-商机-跟进链路完整，适合展示业务流程设计）
3. **ERP 企业资源管理系统**（模块多、边界大，建议在工单与项目管理验证后启动）
