# 03 企业业务应用

> 企业办公与经营类系统：**CRM / ERP / PMS / OA / BPM / HRM**。全部构建在 [OpenBiz 平台内核](/instances/platform) 之上——复用多租户、权限、状态机、表单，只写领域模型。审批、流程、表单与经营业务同属本模块，共用同一底座。

**项目状态图例**：✅ 已验证 · 🔧 验证中/在建 · 📋 规划中（尚未开始实现）

## 📌 模块简介

本模块 = **1 个平台内核 + 6 个垂直应用**。平台做「通用能力」，应用做「领域模型 + 配置」。新增办公 / 业务系统时按扩展机制接入，无需重造底座。

## 🏗️ 模块架构

```
┌ 垂直应用层（薄：领域模型 + 表单/流程配置）
│   CRM · ERP · PMS · OA · BPM · Form
├ 平台内核 · OpenBiz（一次建深，覆盖通用能力约 80%）
│   多租户/数据隔离 · RBAC/行级权限 · 工作流引擎 · 动态表单引擎
│   审计日志 · 消息通知中心 · 导入导出/报表 · 开放 API/SSO
└ 数据层 · MySQL 8 · Redis · 对象存储 · 消息队列
```

详见 [平台内核 · OpenBiz](/instances/platform)（含内核能力清单与「如何接入新办公软件」）。

## 🎯 覆盖率视角（各系统做到 80% 核心链路）

| 系统 | 已覆盖的核心链路 | 尚未覆盖（深水区） |
|---|---|---|
| CRM | 客户 → 商机 → 成交 + 漏斗统计 | 线索、跟进、行级权限、趋势 |
| ERP | 供应商 → 采购单 → 收货 + 采购统计 | 库存、销售、应收应付、物料 / BOM |
| PMS | 项目 → 任务 → 看板 | 甘特图、工时、资源负载、预算 |
| OA | 请假 / 公告双状态机 | 待办聚合、审批中心接 BPM、移动端 |
| BPM | 流程定义 / 实例状态机 | 可视化设计器、规则引擎、监控大盘 |
| HRM | 组织 / 档案 / 编制 / 合同 / 考勤 / 假勤（M1–M2 已验证）；薪酬 / 招聘 / 绩效待建 | 培训、自助、报表、移动端 |

> 判断标准：核心链路端到端跑通（有状态流转、有权限隔离、有统计）即视为「能用」，对应约 80% 的通用需求。

## 🧰 技术栈 / 开发语言

| 分层 | 技术 |

| 前端 | Vue 3 + TypeScript |

## 🚀 建设优先级

1. **平台内核**（多租户 + 状态机，已完成，5 个 consumer 验证）
2. **PMS**（与工单任务模型最接近，复用度最高）
3. **CRM**（客户-商机-漏斗链路清晰）
4. **ERP**（工程量最大，单据链最完整）
5. **OA**（应用组装层，复用 BPM 流程）
6. **BPM**（流程底座，技术展示度最高）
7. **HRM 人力资源**（全员高频，M1–M2 组织/档案/编制/合同/考勤/假勤已验证，208 条断言）

> 实际落地顺序（OpenBiz consumer 编号）：PMS → CRM → ERP → OA → BPM，均已完成最小闭环 E2E。
