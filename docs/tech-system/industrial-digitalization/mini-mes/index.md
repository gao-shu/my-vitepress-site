## 一句话

做一个**可持续演进的工业数字化实验项目**：先跑通设备到监控页的最小闭环，再按需引入 MQTT、业务能力与 AI，最终开源到 GitHub。

不是「完整商业 MES」，也不是「工业数字化教程」。

---

## 要证明什么

1. **Java 全栈**：Gateway / 后端 / 简单前端能串起来  
2. **工业数字化理解**：协议接入、实时状态、业务与测点分离  
3. **工程判断**：知道什么时候该上 MQTT / 时序库 / 微服务，什么时候不该  

以后叠加 AI（告警摘要、知识问答等）也挂在这个项目上，而不是另起炉灶。

---

## V0 范围（做）

- 设备模拟（温度 / 压力等）  
- Gateway 采集（优先 Modbus TCP 模拟）  
- HTTP 上报到 Spring Boot  
- MySQL（业务与历史）+ Redis（在线状态 / 最新值）  
- Vue：设备列表、在线状态、实时值、简单历史曲线  

## V0 明确不做

- MQTT / EMQX  
- TDengine / 微服务 / K8s  
- 完整工单、工艺、追溯、OEE  
- 组态大屏、OPC UA 全协议栈  

理由见 [判断记录](../decisions/)。
