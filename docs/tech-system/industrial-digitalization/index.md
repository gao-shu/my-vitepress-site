# 工业数字化实验室

> 不是工业互联网资料库，而是围绕 **Mini MES V0** 持续演进的公开实验场。

用一个可运行的小系统，把设备接入、Gateway、后端与监控页串起来；网站记 **为什么这么做**，GitHub 记 **写出来、跑起来**。


## V0 最小证明链

```text
模拟设备 → Gateway → HTTP → Spring Boot → MySQL + Redis → Vue 监控页
```

先证明「能采、能存、能看」。MQTT、时序库、微服务等见 [判断记录](./decisions/) 与 [架构演进](./mini-mes/architecture)。
