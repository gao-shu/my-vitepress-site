# Node(TS) · 05 常见问题

## 1. 运行时

| 问题 | 怎么看 |
|------|--------|
| 事件循环卡住 | 同步重计算、同步大文件、死循环；迁 worker/别的服务 |
| 内存涨 | 全局缓存无界、监听器未移除、大 Buffer 滞留 |
| 未处理 Promise | 加统一 handler；查漏了的 catch |
| CPU 100% | 别在 Node 里做重图像/加密扫盘 |

## 2. 模块与类型

| 问题 | 怎么看 |
|------|--------|
| ESM/CJS 报错 | 统一模块体系；看 `package.json` 的 `"type"` |
| 类型骗过运行时 | 少用 `as`；zod 收窄外部输入 |
| 路径别名运行失败 | 编译后路径要对；或用运行时支持的解析 |

## 3. Web / BFF

| 问题 | 怎么看 |
|------|--------|
| 级联超时 | 设置显式 timeout；取消下游 |
| 跨域 | 网关或 BFF 统一处理；凭证策略要想清 |
| 和 Java 规则重复 | BFF 只适配；权威规则在 Java |
| WebSocket 掉线 | 心跳、重连、鉴权过期刷新 |

## 4. Electron 相关

| 问题 | 怎么看 |
|------|--------|
| 主进程卡死 | 重 IO 别堵主进程 |
| 权限/杀软 | Windows 现场常见；签名与安装路径 |
| 与后端版本漂移 | 本地协议版本号；不兼容要提示升级 |
