# 后端问题 · 性能

## 我怎么看性能

性能优化的第一原则：

> **先测量，再动手。**

猜「是不是 JVM」「是不是换语言」通常浪费时间。

## 常见路径

1. 看接口耗时拆分：DB / Redis / 下游 / 本机计算  
2. 慢 SQL 与 N+1  
3. 缓存是否打中  
4. 池是否打满（线程、连接、HTTP）  
5. 最后才是 GC、语言级微优化  

## 我的默认策略

- 分页、限流、超时是基本盘  
- AI 生成等慢操作必须异步，别同步扛在网关后面  
- 优化要有前后对比数字，否则不算做完
