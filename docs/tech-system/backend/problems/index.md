# 后端问题总览

这里沉淀的是 **跨语言的工程问题**：出了状况我怎么理解、怎么处理。  
不是面试题库（细题在就业指南），也不绑死某一门语言。

| 主题 | 我关心的核心问题 |
|------|------------------|
| [并发](./concurrency.md) | 线程/协程用砸了怎么办？资源怎么封顶？ |
| [数据库](./database.md) | 为什么慢？事务边界怎么划？ |
| [Redis](./redis.md) | 缓存一致性、击穿穿透、锁 |
| [MQ](./mq.md) | 丢失、重复、积压 |
| [分布式](./distributed.md) | 要不要拆？一致性怎么做够用？ |
| [网络](./network.md) | 超时、重试、幂等 |
| [性能](./performance.md) | 先量再猜；瓶颈常在 IO/SQL |
| [安全](./security.md) | 鉴权、注入、密钥与越权 |

**原则：** 先有边界与可观测，再谈中间件名词。
