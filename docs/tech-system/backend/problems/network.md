# 后端问题 · 网络

## 我怎么看网络问题

服务之间全是网络：超时、重试、半失败是常态。  
语言不重要，**契约与超时策略**重要。

## 常见坑

| 现象 | 常见根因 | 处理方向 |
|------|----------|----------|
| 偶发超时 | 下游慢、线程池满、DNS/连接 | 超时分层；熔断；连接池 |
| 重试放大故障 | 无脑重试非幂等接口 | 只对幂等重试；退避 |
| 连上了但业务错 | 连错环境、路径、HTTPS 证书 | 配置分离；健康检查 |
| 跨语言调不通 | JSON 字段、编码、Content-Type | 先用 curl/Postman 定契约 |

## 我的默认策略

1. 所有出站调用：超时 + 日志（含耗时）  
2. 重试必须幂等  
3. Java ↔ Python/Node：先把 API 契约写死再联调  

见 [跨语言调用](/tech-system/integration/cross-language-interop)。
