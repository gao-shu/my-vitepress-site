# 我怎么看 Java

> 不是语法课。是：**定位与取舍。**

## 核心特点（在我眼里）

- **工程型语言**：强调可维护、可协作，而不是写起来最短  
- **静态类型 + 成熟工具链**：大项目里改起来相对敢下手  
- **生态绑死企业场景**：ORM、中间件、监控、招聘市场都围绕它转  
- **「慢热」**：启动和样板代码有成本，但换来的是长期可预期  

一句话：Java 卖的是 **可控与存量**，不是爽感。

## 和本站其它语言的分工

| 语言 | 角色 |
