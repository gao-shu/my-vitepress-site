# Spring Cloud：用过 ≠ 该用

我用过 Nacos、Feign、网关限流、XXL-JOB 等，但立场很明确：

> **能单体稳定交付，就不要先拆。**

微服务解决的是组织与规模问题；中小团队拆不好只是增加运维与排查成本。

## 判断

| 场景 | 态度 |
|------|------|
| 简历 / 面试 | 讲清用过哪些组件、解决什么调用 / 配置问题 |
| 架构选择 | MES、多数业务中台 → **轻量单体优先** |
| 真有多团队边界 | 再拆；配置中心 / Feign 按约束引入 |
