# 我在项目里的实际选择

| 场景 | 选择 |
|------|------|
| 业务 API | Spring Boot + MyBatis-Plus（或团队既有 ORM） |
| 缓存 | Redis + 明确的缓存策略 |
| 任务 | 本地异步 / XXL-JOB / 队列，按可靠性要求升 |
| AI 编排 | Java 管状态与配额；Python 管模型胶水 |
| 拆服务 | 默认不拆；配置中心 / Feign 仅在已有架构约束时用 |

## 一句话

Spring 对我意味着：**用约定换交付速度，用容器换可维护性。**  
把它当教材背，不如把它当「出问题能定位的工具箱」。
