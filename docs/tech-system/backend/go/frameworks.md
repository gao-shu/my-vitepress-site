# Go 框架总结

---

## Gin

- 轻量、路由清晰，国内资料多  
- 写小 API 的常用选择  

---

## Echo / Fiber

- Echo：中间件与生态成熟度不错  
- Fiber：Express 风格，追求性能与上手速度  

**判断：** 小服务用 Gin 足够；不必三个都精通。

---

## 标准库 net/http

- 很多场景甚至不需要框架  
- 依赖更少、行为更可控  

---

## 我的选择

| 场景 | 选择 |
|------|------|
| 练习 / 小工具 API | Gin 或标准库 |
| 读别人项目 | 能看懂 Gin/Echo 即可 |
| 生产主业务 | 仍默认 Java |

**原则：** Go 框架够用就行，深度让给 Java/Spring 与后端问题沉淀。
