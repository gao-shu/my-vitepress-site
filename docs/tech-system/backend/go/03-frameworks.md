# Go · 03 框架与生态

## 1. 标准库 net/http

很多场景 **甚至不需要框架**：依赖少、行为可控、长期可读。

适合：内部小工具、探针、简单 API。

## 2. Gin

- 轻量、路由清晰，国内资料多  
- 写小 API 的常用选择  
- 中间件、绑定、校验够用  

## 3. Echo / Fiber

- Echo：中间件与生态成熟度不错  
- Fiber：Express 风格，追求性能与上手速度  

**判断：** 小服务用 Gin 或标准库足够；不必三个都精通。读别人项目时能看懂即可。

---

## 4. 周边

| 类别 | 常见选择 |
|------|----------|
| 配置 | env / viper（按需） |
| 日志 | slog（新标准）/ zap |
| DB | database/sql + 轻封装；重 ORM 谨慎 |
| 路由生态 | chi 等也很常见 |

原则：**Go 框架够用就行**，深度让给 Java/Spring 与 [后端问题](../problems/) 沉淀。

| 场景 | 选择 |
|------|------|
| 练习 / 小工具 API | Gin 或标准库 |
| 读别人项目 | 能看懂 Gin/Echo 即可 |
| 生产主业务 | 仍默认 **Java** |
