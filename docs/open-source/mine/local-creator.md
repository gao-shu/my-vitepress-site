## 它是什么

本地桌面端 **AI 漫创工具**：

- 创作工坊 + 无限画布  
- **无需登录**  
- 模型 Endpoint / API Key **自备**，第三方费用自理  
- 本软件 **不提供** 云充值或公司后台  

定位：把创作链路留在本地，模型调用交给用户自己的 Key。
