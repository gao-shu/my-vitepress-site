## 它想解决什么

**模型接入 / 桌面侧模型工作台**：把常用模型 Endpoint、Key、试调、简单编排收拢到一个本地可用的桌子上，减少每次接模型都从零拼脚本。

（具体功能以仓库 README 为准，此处随迭代更新。）

## 和另外两个怎么分工

| 项目 | 重心 |

| OpenBiz | 中小业务 / 后台交付 |
