# 记账与月度复盘

> 示例文章：目标是「看见现金流」，不是做出完美表格。

## 最小记账法

只分 4 类即可起步：

| 类别 | 例子 |
|------|------|
| 必须支出 | 房租、水电、通勤、基础伙食 |
| 生活弹性 | 外卖升级、社交、订阅 |
| 成长投入 | 课程、书籍、健身 |
| 长期目标 | 应急金、投资定投 |

工具随意：表格、App、笔记都行，**能坚持比工具高级更重要**。

## 每月 30 分钟复盘

1. 本月总流入 / 总流出  
2. 哪一类超预期了？原因是什么？  
3. 下月只改 **1 个**行为（例如少一次无意义订阅）
