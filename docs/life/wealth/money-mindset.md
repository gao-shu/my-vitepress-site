# 理财认知入门（非荐股）

> 示例文章：只谈原则，不推荐具体产品或个股。

## 几条底线

1. **先理解，再出手**：不懂的结构不要碰  
2. **风险与收益同在**：承诺稳赚的多半有问题  
3. **时间与分散**：比频繁操作更重要  
4. **费用会吃收益**：关注隐性成本  

## 常见误区

- 把「听说能赚」当成研究结论  
- 应急金还没建好就上高波动资产  
- 用借来的钱博收益  

## 建议顺序（个人向）

记账看清现金流 → 应急金 → 再考虑长期、可承受波动的配置。
