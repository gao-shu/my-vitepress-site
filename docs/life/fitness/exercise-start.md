# 运动起步：每周最小可行计划

> 示例文章：目标不是练成运动员，而是「每周都能发生」。

## 原则

- **频率优先于强度**：先保证次数，再谈配重或配速  
- **和日程绑定**：固定工作日某个时段，减少临场决策  

## 示例周计划（可直接改）

| 日 | 内容 | 时长 |
|----|------|------|
| 一 | 快走 / 慢跑 | 20–30 分钟 |
| 三 | 徒手力量（深蹲、俯卧撑、平板支撑） | 15–25 分钟 |
| 五 | 拉伸 + 散步 | 20 分钟 |
| 周末 | 可选补一次户外活动 | 随意 |

连续两周能完成 80%，再考虑加量。

## 常见坑

- 第一周就上高强度 → 容易断  
- 只靠心情运动 → 用日历提醒更稳  
- 完全不热身 → 肩颈腰更容易不适
