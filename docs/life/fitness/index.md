# 运动健身

> 模块定位：用可执行的小计划把身体状态撑住，服务长期学习与工作。  
> 下面几篇是示例骨架，方便你后续按自己的实践替换、加深。

## 建议阅读顺序

1. [睡眠与作息入门](./sleep-basics) — 先稳住恢复
2. [运动起步：每周最小可行计划](./exercise-start) — 用最小成本动起来
3. [久坐与肩颈：程序员常见问题](./desk-posture) — 针对长时间电脑工作

## 使用方式

- 每周只改 1 个习惯，观察两周再加下一项
- 记录比完美更重要：练了几次、睡得如何，写下来即可
- 有伤病或不适，以专业建议为准；这里只做个人实践笔记
