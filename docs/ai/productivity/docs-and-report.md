# 文档、周报与沟通提效

## 场景与问题

程序员的时间黑洞里，代码之外总有那么一块：周报周五下午憋一小时，技术文档拖到 deadline 才写，会议纪要散会后没人想动，跨部门沟通的消息来回好几轮。这些事单件都不难，但架不住每周都来，而且大多要求“写清楚、说人话、有条理”——恰好是 AI 擅长的部分。

但直接让 AI“帮我写个周报”，产出通常是空话合集：“本周推进了各项工作，取得阶段性成果，与相关方保持密切对齐”。这种东西发出去，同事看完不知道你干了什么，领导看完记不住你。问题在于：AI 没有你的事实，只能用套话填坑。模板化就是解决这个的——你喂事实，它管表达。

## 做法

### 1. 模板化：先定结构，再填事实

把高频文档固化成模板，AI 负责按模板组织语言。几个验证过的模板：

- **周报**：本周完成（逐条，带结果和数据）/ 进行中（进度百分比 + 预计完成时间）/ 风险与阻塞（需要谁协调什么）/ 下周计划。
- **技术文档**：背景与问题 / 方案选型与理由 / 详细设计 / 未决问题。让 AI 先按这个骨架问你问题，你答完它再成文——“以问代写”比“直接写”质量高一档。
- **会议纪要**：丢原始记录（文字稿、聊天记录、你自己记的流水账）进去，要求输出“结论 / 待办（谁、什么事、什么时候）/ 争议点”，不要抒发感想。
- **沟通消息**：说清楚背景、你要对方做什么、截止时间三件事，让 AI 压缩到三句话以内。

模板的作用是把“写什么”固定下来，AI 只解决“怎么写”，产出立刻从空话变成干货。和写代码要先定接口一个道理：结构稳了，填充就是机械劳动。

### 2. 事实核对：AI 只重组，不创造

给 AI 的输入必须是事实：你的 commit 记录、TODO、会议原话、项目数据。成文后逐条核对三件事：

- **数字对不对**：完成率、耗时、数据量，它有四舍五入甚至凭空“优化”的倾向。
- **人名和时间对不对**：谁负责什么、 deadline 是哪天，错了直接得罪人。
- **有没有编出来的“进展”**：它会把“计划做的”写成“已完成的”，把 A 项目的事安到 B 项目上。

经验是：凡是具体的数据、日期、专有名词，一律默认它可能看错，回原始材料对一遍。宁可少写一条，不能写错一条——写错的周报比不写更伤。一个省力的技巧：让它在成文时给每条内容标注来源（对应哪个 commit、哪段会议原话），核对时按标注走。

### 3. 保持个人风格

AI 的默认文风偏“公文腔”，用得多了别人一眼看出是模板。三个办法：

- **存一段自己的样本文档**：你写得最顺的一篇周报或文档，让它“模仿这个语气和句式”。
- **写明禁忌**：不用“赋能、抓手、闭环、对齐”这类词，不写“综上所述”式的空结尾，短句为主。
- **终稿自己读一遍**：把不像你说的话改掉，通常十几分钟，比完全从头写省一小时。

风格的本质是可辨识度。长期协作的人会形成你的文字印象，这个印象值得维护。

### 4. 一次典型的使用流程

以周报为例，完整的动作链是：

1. 周五下午花五分钟，从 commit 记录和 TODO 里把本周事实列成要点（草稿级，不用组织语言）。
2. 把要点 + 周报模板丢给 AI：“按这个模板组织成周报，只使用我给的要点，不要添加我没有的信息。”
3. 逐条核对：数字、日期、项目名回原始记录对一遍。
4. 读一遍终稿，删掉空话，改掉不像自己的句式。
5. 发出，同时把这周新出现的表达习惯并入你的样本文档。

全程十来分钟，其中 AI 工作不到一分钟，你的时间花在事实和终审——这两块本来就省不掉，也不该省。

### 5. 常见的坑

- **上来就让它“自由发挥”**：没有模板和事实输入，得到的一定是套话，然后你花更多时间改。
- **核对时只扫格式不看内容**：排版工整最具有欺骗性，错的事实往往藏在最通顺的句子里。
- **对不同人发同一份措辞**：给领导的汇报和给同事的同步关注点不同，模板要按读者分开建。
- **把敏感信息喂给不合适的工具**：未公开的业务数据、客户信息，先确认工具的数据政策，必要时脱敏或本地化处理。

## 关键要点

- 高频文档先定模板，AI 按骨架填肉；结构固定，内容才有干货。
- “以问代写”：让 AI 先按骨架提问，你答事实，它再成文。
- 输入只给事实（commit、原话、数据），输出逐条核对数字、人名、日期。
- 具体信息默认存疑，可要求标注来源回源核对，写错比不写更伤。
- 用样本文档 + 禁用词清单锚定个人风格，终稿自己读一遍。
- AI 省的是组织语言的时间，事实和判断必须来自你。

## 小结

文档和沟通类工作的提效公式是：模板管结构，事实核对管可信度，风格约束管辨识度。AI 把“从空白页开始”的成本降到接近零，你只需要保证喂进去的是真材料、拿出来的是核过的真内容。一周下来，周报、纪要、沟通消息这些零碎时间加起来省一两个小时不夸张，而它们恰恰是原本最不想动的活。
