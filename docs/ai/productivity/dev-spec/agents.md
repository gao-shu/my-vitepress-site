## 协作原则（可迭代）

- **Rules**：存放必须遵守的规则、限制和边界，不写操作教程，不重复详细开发规范。
- **Skills**：沉淀经过验证、可重复执行的工作流程、操作方法和验收标准。
- **Agents**：根据实际任务需要配置专业角色；简单任务由主 Agent 完成，复杂任务再考虑多 Agent 协作。
- **MCP / Tools**：提供外部系统、数据源和工具调用能力，按任务需要使用。
- **Hooks / Scripts**：处理适合自动化的检查、验证和重复操作。
- **验收**：以实际代码变更、任务验收标准、测试结果及必要的文档交付为依据。
