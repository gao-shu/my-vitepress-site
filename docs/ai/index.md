# AI 赋能

> 用 AI 提升效率，改善生活，探索创造财富的新可能。

这套结构不按 AI 技术种类划分，而是按照**个人如何利用 AI 创造价值**来划分：

| 模块 | 定位 | 一句话 |
|------|------|--------|
| [AI 认知成长](/ai/cognition/) | 获得知识与判断力 | 知道做什么、为什么做 |
| [AI 生产力](/ai/productivity/) | 把想法变成行动 | 把事情真正做出来 |
| [AI 创作表达](/ai/creation/) | 把成果传播出去 | 让成果被看见、被传播 |
| [AI 商业探索](/ai/business/) | 寻找需求，验证价值 | 让价值获得市场验证 |

## 这四个模块是一条逻辑链

**认知成长** 知道做什么、为什么做 → **生产力** 把事情真正做出来 → **创作表达** 让成果被看见、被传播 → **商业探索** 让价值获得市场验证。

这是一条逻辑链，不是强制流程。比如研究赚钱机会时，可能先发现需求，再学习工具、制作内容，最后验证收益。

## 怎么用

- 想系统入门：按 1 → 2 → 3 → 4 的顺序走
- 已有明确目标：直接进入对应模块
- 每个模块下的二级分类已固定，文章会持续补充到对应分类下
