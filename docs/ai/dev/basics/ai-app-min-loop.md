# AI 应用最小链路

> 类型：`[决策]` · 证明「会做系统」的骨架，不是框架教程。

聊天框演示 ≠ 应用。能讲清楚下面这条链，面试和落地都够用。

```text
需求 / 场景
    ↓
Prompt + 结构化输出（JSON / 表单字段）
    ↓
模型 API 调用（超时、重试、降级）
    ↓
业务落库 / 任务状态（提交 → 执行 → 成功/失败）
    ↓
人工验收或规则校验
    ↓
可观测（日志、费用、失败原因）
```

## 每一环最少要有什么

| 环节 | 最少交付 |
|------|----------|
| 需求 | 输入是什么、输出验收标准、失败怎么办 |
| Prompt | 角色、约束、输出格式；能版本化，不靠聊天记录 |
| 调用 | API Key 不进前端；超时/重试；必要时换备用模型 |
| 状态 | 异步任务有状态机；可查询、可重试，不「点了就丢」 |
| 验收 | 人审或规则（字段校验、敏感词、业务阈值） |
| 观测 | 能回答：今天多少次、多少钱、失败卡在哪 |
