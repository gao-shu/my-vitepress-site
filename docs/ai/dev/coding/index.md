# AI Coding

AI Coding 不是让 AI 替代开发，而是把 AI 融入软件工程完整交付流程，在保证架构、质量和可维护性的前提下提升开发效率。

---

## 我的定位

- 10 年 Java / 全栈开发经验
- Java / Spring / MySQL / Redis / MQ 等后端工程能力
- 正在强化 AI 应用开发能力
- 使用 Cursor 等 AI Coding 工具参与真实项目开发
- 重点关注：AI 生成代码的架构判断、Review、Debug、测试和交付

一句话：

> **工程经验 + AI Coding + AI 应用开发** —— AI 提速，人对架构、质量与最终结果负责。

---

## AI Coding 工作方式

```text
需求
 → 拆解
 → 上下文
 → AI 协作
 → 实现
 → Review
 → 测试
 → Debug
 → 交付
 → 复盘
```

分工很清楚：

- **AI**：提高实现与检查效率（生成、扫描、草稿）
- **开发者**：需求理解、架构设计、技术决策、质量控制、最终交付

AI Coding = **AI + 软件工程**，不是「会用 Cursor」。
