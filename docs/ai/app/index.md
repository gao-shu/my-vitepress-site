# AI 应用

我关注的不是「AI 有哪些工具」，而是 **AI 如何真正进入软件系统和业务流程**。

工具与原理在 [AI 技术](/ai/dev/)；这里只讲切哪里、先做什么、怎么做成可用闭环。

---

## 三个分类

### AI 应用

AI 接到真实业务场景：企业流程、MES / 工业现场、内容生产等。主题可以很多，**不拆成长期子菜单**。

### Agent 应用

如何用 Agent（Tools / Skills / Context）解决真实问题、构建可执行应用。与 [技术 → Agent](/ai/dev/agent/agent-overview) 区分：那边讲 Agent 本身，这边讲落地用法。

> 暂无足够真实的 Agent 应用文章，分类先留空，有内容再挂上。

### AI 产品

从功能想法走到可验证的产品最小闭环：谁用、什么任务、成功标准、怎么评测。

---

## 我的判断

- AI 应该进具体业务流程，不要孤立成一个聊天窗口。
- 不是处处都该上 AI。频繁、规则清楚、信息量大的环节更值得先试。
- 核心不只是模型，而是模型 + 上下文 + 工具 + 业务规则 + 人工验证。
- 高风险环节先做辅助，不要直接自动拍板。
- 一个功能有没有价值，最终看真实任务和结果，不看 Demo 漂不漂亮。
