# 平台选择与个人定位

## 场景与问题

开始做内容时最常见的冲动是"全都要"：博客、掘金、知乎、公众号、小红书、B站、X 各注册一遍，每处发一条，然后一周内全部停更——因为单是排版同步就耗尽了所有业余时间。

另一个极端是纠结到不动手：哪个平台流量大？公众号还有没有红利？B站适不适合技术内容？想一个月，一篇没发。

还有定位问题：账号名叫"XX的技术笔记"，今天发 JVM 调优，明天发 AI 绘画，后天发读书笔记——算法和读者都识别不出你是谁，推荐量始终上不去。

对有本职工作的工程师来说，还有个隐藏顾虑：**做账号会不会和本职工作冲突？** 领导看到我下班搞副业怎么想？内容里能不能提公司的事？

核心问题其实只有三个：**在哪发（平台）、我是谁（定位）、怎么和主业相处（边界）**。想清楚这三点，比在十个平台各发一条有效得多。

## 做法

### 1. 平台选择：1 个主平台 + 1 个副平台，其余当分发渠道

原则：**主力运营不超过 2 个**，多出来的全部降级为"同步分发"，只复制不运营。

选择按内容形态对号入座：

| 你的内容形态 | 主平台候选 | 理由 |
|-------------|-----------|------|
| 深度技术长文 | 掘金 / 博客 + 知乎 | 搜索长尾强，长文友好 |
| 观点与短想法 | X / 即刻 | 反馈快，适合日更练手 |
| 图文干货、教程清单 | 公众号 / 小红书 | 传播和沉淀兼顾 |
| 演示型、教程视频 | B站 / 视频号 | 视频形态天花板高 |

判断标准三条：

- **你的目标读者在不在那**：写给同行看去社区，写给转行者看去知乎/小红书；
- **你的内容形态和平台匹配**：长文硬塞进短内容平台 = 自废武功；
- **你能不能持续**：选你刷得最多的平台，你对它的语感是现成的。

我的建议起步组合：**博客当根据地（资产自有），挑 1 个社区平台当主战场**。其余平台用上一篇的"一稿多发"流程做被动分发，不花运营精力。

### 2. 定位：一句话说清"我为谁提供什么"

定位不是口号，是一个过滤器，帮你决定"什么该发、什么不该发"。公式：

> **我帮【什么人】解决【什么问题】，用【什么独特角度】**

写给工程师的账号，一个可用的定位示例：

- "10 年后端，写 AI 工程化落地的坑与方法"——人群（开发者）、问题（AI 落地）、角度（实战踩坑）；
- "全栈妈妈的前端科普"——人群、问题、身份角度各不同，但同样具体。

检验定位是否合格的三个问题：

1. 只看名字+简介，陌生人 5 秒内知道你写什么吗？
2. 来了一个新选题，能立刻判断"这符合/不符合我的定位"吗？
3. 同类账号里，你的角度有没有差异化（身份、领域交叉、方法论）？

定位要**窄启动再放宽**：先吃透一个细分（比如"Java 性能调优"），有稳定读者后再自然扩展到相邻领域（"后端工程化"）。宽泛定位看起来天花板高，实际上哪个流量都吃不到。

### 3. 内容栏目化：把定位拆成 3-4 个固定栏目

栏目化是定位的执行层，好处是**选题不用每次从零想**，读者也知道会看到什么。做法：

- 把定位拆成 3-4 个常设栏目，每个栏目一句说明、固定视觉标识（封面模板/标题前缀）；
- 示例（技术向）：`踩坑实录`（真实排障案例）/ `工具箱`（高频工具用法）/ `方法论`（流程与思路）/ `周刊`（本周所见）；
- 每个栏目设最低占比，比如核心栏目占 60%，防止跑偏；
- 栏目可以季度调整：数据好的加强，持续没反响的砍掉。

栏目化之后，"这周发什么"从开放题变成选择题——从哪个栏目里出一篇，效率完全不同。

### 4. 与本职工作互补而非冲突

这是很多人没想透的一点，处理好了是双赢：

- **内容方向选与主业"相邻"的**：主业做后端，账号写后端/AI 工程化——工作素材直接变内容，内容沉淀又反哺工作技能，互相喂养，也更容易坚持；
- **红线三条**：不泄露公司未公开信息（代码、数据、架构细节）；不在内容里评价公司和同事；拿不准的案例做脱敏和虚构化处理；
- **时间上用增量不抢存量**：写"我本来就要总结的东西"——工作复盘、技术调研顺手成文，而不是每天额外硬造 2 小时；
- **对主业是加分项**：持续输出的技术博客是最好的简历和行业名片，多数情况下领导知情并不反对；真有竞业或保密顾虑，就写通用方法论，避开公司业务领域。

判断标准很简单：**这份内容敢不敢让同事和领导看到**。敢，说明边界对了；不敢，说明该改。

## 关键要点

- 平台做减法：1 个主平台 + 1 个副平台认真运营，其余只做被动分发；
- 定位一句话公式：帮【谁】解决【什么问题】，用【什么角度】——它是选题过滤器，窄启动后逐步放宽；
- 栏目化把定位变成 3-4 个常设专栏，选题从开放题变选择题，按数据季度调栏目；
- 与主业的关系：方向选相邻领域互相喂养，守住保密红线，用工作复盘做素材，时间用增量；
- 内容的最低检验：陌生人 5 秒看懂你是谁，同事看到也不尴尬。

## 小结

平台选择和定位的本质是**做减法**：少而准的平台、一句清晰的定位、几个固定栏目，加上和本职工作一致的方向。这套确定性一旦建立，剩下的"发什么、怎么发"都变成填空题——个人品牌不是靠铺量铺出来的，是靠一个清晰的标签在少数人心里反复出现。
