# AI 大模型选型指南

> **更新日期**：2026-05  
> **目标**：在不同环境下（本地/云端/混合），按任务（写代码/写文档/RAG/Agent）选到「够用且稳定」的模型。

---

## 一、先定 3 个变量

| 变量 | 选项 | 说明 |
|------|------|------|
| **环境** | 本地 / 云端 / 混合 | 决定可用模型范围与成本结构 |
| **任务** | 代码 / 文档 / RAG / Agent | 决定能力侧重点 |
| **约束** | 隐私 / 预算 / 延迟 / 上下文长度 | 决定最终取舍 |

---

## 二、2026 主流模型梯队

### 第一梯队：综合能力最强

| 模型 | 擅长领域 | 推荐场景 | 注意 |
|------|---------|---------|------|
| **GPT-4o** | 代码、推理、多模态 | 关键任务、复杂重构 | 云端 API，成本较高 |
| **Claude 3.5+ / 4** | 长文本、写作、对齐 | 文档生成、代码审查 | 长上下文表现优异 |
| **Gemini 2.5 Pro** | 多模态、超长上下文 | 视频理解、超大文档 | Google 生态集成 |

### 第二梯队：性价比之选

| 模型 | 擅长领域 | 推荐场景 | 注意 |
|------|---------|---------|------|
| **DeepSeek-V3 / R1** | 代码、推理 | 日常编码、批量任务 | 性价比极高，中文友好 |
| **Qwen 2.5 / 3** | 中文、工具调用 | 国内场景、RAG、Agent | 开源可本地部署 |
| **Llama 4** | 通用、生态 | 本地部署、实验 | 开源社区支持最好 |

### 第三梯队：轻量与专用

| 模型 | 擅长领域 | 推荐场景 | 注意 |
|------|---------|---------|------|
| **Phi-4** | 轻量推理 | 边缘设备、简单任务 | 微软出品，小而精 |
| **Mistral Small / Large** | 多语言、工具 | 欧洲场景、多语言 | 工具调用能力不错 |
| **GLM-4** | 中文 | 国内合规场景 | 智谱出品，本地友好 |

## 三、按环境选型

### 云端优先（推荐大多数场景）

**适用场景**：
- 需要最强模型能力
- 有稳定的网络和 API 预算
- 数据无需本地保留

**推荐组合**：
```
关键任务 → GPT-4o / Claude 4
日常任务 → DeepSeek / Qwen API
批量任务 → 性价比最高的模型
```

### 本地部署（隐私 / 离线 / 成本敏感）

**适用场景**：
- 数据不能出企业内网
- 需要低延迟响应
- API 费用不可控

**推荐组合**：
```
主力推理 → Qwen 2.5 (14B~72B) / Llama 4 (8B~70B)
轻量任务 → Phi-4 / Mistral 7B
管理工具 → Ollama + Open WebUI
```

### 混合方案（推荐）

**最佳实践**：
```
┌──────────────────────────────────┐
│  本地模型 (Qwen/Llama)           │
│  ├─ 草稿生成 / 批量总结          │
│  ├─ 结构化提取 / 分类            │
│  └─ 离线 / 隐私任务               │
├──────────────────────────────────┤
│  云端模型 (GPT-4o/Claude)        │
│  ├─ 关键决策 / 复杂推理          │
│  ├─ 最终润色 / 长文档处理        │
│  └─ 高价值任务                    │
└──────────────────────────────────┘
```

**路由建议**：
| 任务类型 | 路由目标 |
|---------|---------|
| 写简历 / 重要答复 / 复杂重构 | 云端强模型 |
| 批量出题 / 结构化提取 / 初稿 | 本地 / 性价比云端 |
| 隐私数据 / 离线任务 | 本地模型 |

## 四、按场景选型

### 日常编码提效

| 优先级 | 推荐 |
|-------|------|
| 首选 | GPT-4o / Claude（关键任务） |
| 备选 | DeepSeek（代码向）/ Qwen 2.5 |
| 本地 | Qwen 2.5 / Llama 4（中小尺寸） |

### 文档写作与知识库

| 优先级 | 推荐 |
|-------|------|
| 首选 | Claude（长文档 / 表达一致性） |
| 备选 | GPT-4o（综合能力强） |
| 本地 | Qwen 2.5（中文写作）/ Llama 4 |

### RAG 知识库问答

| 优先级 | 推荐 |
|-------|------|
| 云端 | GPT-4o / Claude（回答质量更稳） |
| 本地 | Qwen 2.5 / Llama 4（配合检索片段） |
| 核心 | 切块策略 > 召回质量 > 模型选择 |

> **RAG 的真相**：核心不是「换更大模型」，而是切块、召回、重排、引用与拒答策略。

### Agent 多步任务

| 优先级 | 推荐 |
|-------|------|
| 云端首选 | GPT-4o / Claude（工具调用最稳定） |
| 本地备选 | Qwen 2.5 / Llama 4（务必加输出校验） |
| 关键点 | 结构化输出 / 函数调用稳定性 > 推理能力 |

## 五、最少折腾版落地方案

### 版本一（立刻能用）

```
主力：云端 API（GPT-4o 或 DeepSeek）
辅助：Ollama + Qwen 2.5（本地实验）
工具链：Cursor + Continue
```

### 版本二（团队协作）

```
主力：云端 API + LLM Gateway（统一切换/日志/重试）
辅助：本地模型做离线/批量
工具链：Cursor + MCP Server + 内部知识库
```

### 版本三（企业级）

```
主力：混合推理集群（自建 + 云端）
辅助：模型路由 + A/B 测试 + 监控
工具链：自定义 Agent + MCP + RAG Pipeline
```
