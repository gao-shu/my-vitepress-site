## 二、AI 编辑器 / IDE 选型

### Cursor（推荐 ⭐⭐⭐⭐⭐）

| 维度 | 评价 |
|------|------|
| **适合人群** | 全栈 / 前端 / 需要深度 AI 辅助的开发者 |
| **核心优势** | AI 原生体验，Tab 补全准确率高，Composer 多文件编辑 |
| **模型支持** | GPT-4o、Claude、自研模型，支持 BYOK（自带密钥） |
| **价格** | 免费版有限额，Pro $20/月 |
| **学习曲线** | 低（VS Code 用户几乎零成本迁移） |

**最适合**：日常开发主力，需要 AI 深度融入编码流程。

### VS Code + Copilot / Continue

| 维度 | 评价 |
|------|------|
| **适合人群** | 不想换 IDE、需要灵活搭配的用户 |
| **核心优势** | 生态最丰富，插件自由组合 |
| **组合方案** | Copilot（代码补全）+ Continue（多模型对话） |
| **模型支持** | 取决于插件，Continue 支持本地 + 云端任意模型 |
| **价格** | VS Code 免费，Copilot $10/月，Continue 免费 |

**最适合**：喜欢 VS Code 生态、需要自定义 AI 流程的用户。

### JetBrains + AI Assistant

| 维度 | 评价 |
|------|------|
| **适合人群** | Java / Kotlin 等重度 JetBrains 用户 |
| **核心优势** | 深度理解项目结构，重构能力强 |
| **模型支持** | 内置 + 可配置第三方 |
| **价格** | IDE 付费 + AI 插件订阅 |

**最适合**：Java 后端、Android 开发等 JetBrains 生态用户。

### Windsurf

| 维度 | 评价 |
|------|------|
| **适合人群** | 追求极致 AI 体验的开发者 |
| **核心优势** | Cascade 模式可自主完成复杂任务，Flow 上下文管理 |
| **注意** | 仍在快速迭代中，功能变化较快 |

## 七、选型决策树

```
你当前用什么 IDE？
├─ VS Code → 你愿意换 Cursor 吗？
│  ├─ 愿意 → Cursor（最佳 AI 体验）
│  └─ 不愿 → VS Code + Copilot + Continue
├─ JetBrains → JetBrains + AI Assistant
└─ 其他/无偏好 → Cursor（门槛最低）

你是否需要本地模型？
├─ 是 → Ollama（首选）+ Open WebUI
└─ 否 → 优先云端 API

你是否需要搭建 AI 工作流？
├─ 是 → Dify（开源首选）/ Coze（快速上手）
└─ 否 → 编辑器 + CLI 足够
```
