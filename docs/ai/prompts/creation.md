# 创意与内容提示词（10 条）

> 选题、脚本、生图时用的 10 条。先给素材，再要结果。
> 通用骨架：背景 → 现状 → 目标 → 约束 → 输出格式，见 [提示词库总览](/ai/prompts/)。

## 模板

### 1. 选题（从素材里长，不凭空要）

```text
背景：我的账号定位是【…】，读者是【具体画像】，我手上有这些真实素材：【踩过的坑 / 项目经历 / 数据】。
任务：给 8 个选题，每个包含：读者会遇到的场景、我的素材能提供什么独特视角、这个选题的“反常识点”是什么。
要求：不要泛题目（如“AI 提升效率的 5 个方法”）；每个选题要能一句话说清“为什么是我来讲”；标出哪些需要补素材才能写。
```

### 2. 短视频脚本（30~60 秒）

```text
背景：平台【抖音/B站/视频号】，受众【…】，我要讲的是【一句话观点】，时长【N】秒。
任务：给脚本，分镜格式：时间 / 画面 / 口播词 / 字幕重点。
要求：前 3 秒必须有钩子（冲突、反常识、具体数字），不要自我介绍开场；口播词按说出来的节奏写，一句话不超过 15 字；结尾给一个可执行的动作或一个开放问题。
```

### 3. 生图提示词（结构化）

```text
背景：我要一张【用途：公众号封面 / 文章配图 / 概念示意】的图，风格参考【…】，画幅【16:9 / 1:1 / 9:16】。
任务：写成结构化提示词，包含——主体（谁/什么，细节到材质）、构图（视角、主体位置、负空间留白）、光线与色调、风格（摄影/插画/3D/扁平）、画幅比例、明确排除项。
要求：给中英两版（中文自用、英文投给生图模型）；不要用“高质量”“大师作品”这类无效词；写清哪里需要留白放文字。
```

### 4. 封面 / 海报文案

```text
背景：这张图用于【平台】，主题【…】，主视觉是【…】，文字区域在【位置】。
任务：给 5 组文案，每组含主标题（不超过 8 字）、副标题（不超过 15 字）、角标一句话。
要求：主标题要能被 3 秒读完；不用问句堆叠；不同组走不同策略（数字型 / 对比型 / 悬念型）；考虑手机端的可读性。
```

### 5. 内容系列规划（10 期）

```text
背景：我要做一个系列，主题【…】，目标【涨粉 / 建立专业形象 / 引流到产品】，每期投入【X】小时。
任务：规划 10 期，每期给标题 + 核心观点 + 与上一期的衔接。
要求：第 1 期做“钩子”（最容易共鸣的问题），第 10 期做“收口”（体系化总结）；中间每 3 期安排一个高信息密度期；标出哪几期可以复用成文章。
```

### 6. 灵感发散（SCAMPER）

```text
背景：现有方案/产品是【…】，我想找差异化方向。
任务：用 SCAMPER 七个角度各给 2 个具体改法（替代、组合、借用、修改、另有用途、消除、重排），每个改法一句话说清改成什么样、解决谁的什么问题。
要求：不要停在概念层（“可以做个性化”这种不算）；每条标注可落地程度（立刻能做 / 需要资源 / 纯设想）。
```

### 7. 内容复用（一篇变五种）

```text
背景：原文是【贴文章/脚本】，核心观点是【…】。
任务：拆成五种形态——一条 60 秒口播、一组 5 张图文卡片（每张一句主文案）、一条 300 字朋友圈、一个问答式互动帖、一份可下载的清单。
要求：保留核心观点，形态之间不要互相复制粘贴；每种标注发布平台和最佳发布时间。
```

### 8. 个人定位（一句话说清你是谁）

```text
背景：我的经历是【…】，擅长【…】，想吸引的人是【…】，最终想转化到【…】。
任务：给 3 个定位表述，每个结构为“我帮【谁】解决【什么问题】，用的是【什么独特方法】”，各不超过 30 字。
要求：要能被同行验证（不能吹）；三个版本分别偏专业、偏亲和、偏结果导向；最后指出这个定位半年后可能遇到的天花板。
```

### 9. 口播稿（能读顺的那种）

```text
背景：主题【…】，时长【N】分钟，听众是【…】，我的说话习惯是【偏口语/偏书面】。
任务：写口播稿，分段给，每段不超过 4 句。
要求：句子短，避免长定语；专业词第一次出现加一句解释；每 90 秒有一个“停一下”的节奏点（提问、转折、小结）；标出可以自由发挥的位置。
```

### 10. 互动与评论区

```text
背景：这条内容讲的是【…】，读者最可能的两种反应是【认同/质疑某点】。
任务：给 10 条评论区引导语 + 3 条针对质疑的回应思路。
要求：引导语要具体（问经历、问场景），不要“你怎么看”；回应质疑时不辩解，先复述对方观点再补信息；不要用“感谢分享”这类空话。
```
